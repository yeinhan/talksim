누가 먼저 연락하는지, 첫마디는 뭔지, 어떤 말을 제일 많이 하는지 알려드려요.

대화 내용은 이 휴대폰 안에서만 분석되고, 어디에도 전송되거나 저장되지 않아요.
대화 파일은 어떻게 받나요?
  1. 카카오톡에서 분석할 채팅방에 들어가요.
  2. 오른쪽 위 ☰ 메뉴 → 아래쪽 ⚙ 설정을 눌러요.
  3. 대화 내용 내보내기 → 텍스트 메시지만 보내기를 골라요.
  4. "파일에 저장"(아이폰) 또는 "내 파일"(안드로이드)에 저장한 뒤, 위 버튼으로 올려요.
