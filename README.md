# 톡심 측정기

카카오톡 "대화 내용 내보내기" 파일을 올리면 누가 먼저 톡했는지(선톡), 첫마디, 자주 쓰는 말, 답장 속도, 읽씹 횟수, 시간대별 대화량과 톡심 점수를 보여주는 재미용 사이트입니다.

- 모든 분석은 브라우저 안에서만 실행되고, 대화 내용은 어디에도 전송·저장되지 않습니다.
- 지원 형식: 안드로이드, 아이폰, PC(윈도/맥), 영어 설정 내보내기 (.txt, .zip)
- 카카오와 관련 없는 개인 프로젝트입니다.

## 구조

- `index.html` 화면
- `src/parser.js` 내보내기 파일 분석기
- `src/stats.js` 통계 계산
- `src/sample.js` 첫 화면 예시 대화(가상 인물)
- `privacy.html` 개인정보처리방침

## 개발

```
npm test                 # 분석기·통계 테스트
python3 -m http.server   # http://localhost:8000 에서 확인
```
